# Projeto Biblioteca MySQL

## Sobre o projeto
Projeto desenvolvido durante uma atividade prática de banco de dados utilizando MySQL Workbench.

## Tecnologias utilizadas
- MySQL
- MySQL Workbench
- SQL

## O que foi desenvolvido
- Criação de banco de dados.
- Criação de tabelas.
- Relacionamento entre tabelas com FOREIGN KEY.
- Inserção e consulta de dados.
- Consultas com INNER JOIN.
- Atualização de registros com UPDATE.
- Exclusão de registros com DELETE.

## Autor
Projeto desenvolvido como atividade de estudo de SQL.
